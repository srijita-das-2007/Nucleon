# Nucleon

## DNA Sequence Analysis Tool

Nucleon is a Python command-line project for exploring DNA sequences and comparing two sequences.

## Features

- Enter a DNA sequence manually or load one from a text file
- Validate DNA sequences using the bases A, T, G, and C
- Calculate sequence length and count each nucleotide
- Calculate GC percentage
- Generate the reverse complement
- Search for a DNA motif
- Convert DNA to RNA
- Translate RNA codons into amino acids
- Compare two DNA sequences and identify differences

## Requirements

- Python 3.x
- No third-party Python packages are required

## How to Run

1. Install Python 3 if it is not already installed.
2. Download or clone this repository.
3. Open Command Prompt in the project folder.
4. Run:

```bash
python main.py
```

## How to Use

Follow the menu displayed in the terminal. Choose DNA analysis, sequence comparison, or exit. For DNA analysis, follow the prompts to enter a sequence or load it from the sample text file.

DNA sequences should contain only A, T, G, and C.

## Limitations

This is an educational project for basic DNA sequence analysis. It should not be used for medical or clinical decisions.
