# 🧬 NUCLEON — DNA Sequence Analysis Tool

NUCLEON is a beginner-friendly, menu-driven command-line tool written in pure Python. It lets you analyze a single DNA sequence or compare two DNA sequences, without any external libraries.

## Problem Statement

Working with DNA sequences by hand is slow and error-prone. Counting bases, finding the reverse complement, transcribing to RNA and translating to a protein all involve repetitive steps. NUCLEON automates these basic bioinformatics tasks in one simple program.

## Features

### 1. Analyze DNA
- **Input options:** type the sequence manually or load it from a text file (`sample.txt`)
- **Validation:** accepts only the bases `A`, `T`, `G`, `C`
- **GC content:** percentage of G and C bases in the sequence
- **Reverse complement:** the complementary strand read in reverse
- **Motif search:** finds the position of a motif (sub-sequence) in the DNA
- **RNA conversion:** converts the DNA sequence to RNA
- **Protein translation:** translates RNA codons into amino acids using the standard codon table, stopping at a stop codon

### 2. Compare DNA Sequences
- Compares two sequences of equal length position by position
- Reports each mutation (e.g. `Position 3 : A --> G = Mutation`)
- Shows the total number of mutations

## Requirements

- Python 3.x
- No external libraries needed

## How to Run

```bash
git clone https://github.com/<your-username>/nucleon.git
cd nucleon
python nucleon.py
```

To use file input, create a `sample.txt` file in the same folder containing a single DNA sequence, for example:

```
ATGGCCATTGTAATGGGCCGCTGAAAGGGTGCCCGATAG
```

## Known Limitations

- Mutation comparison supports only equal-length sequences (substitutions only, no insertions or deletions)
- Motif search reports only the first match (`-1` means not found)
- Translation starts from the first codon of the RNA rather than from the start codon (`AUG`)
- RNA is generated by complementing the input strand (template-strand convention)
- The `Exit` option and invalid-input handling are basic
